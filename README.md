\# A.S Sports Shop Billing System



A Python-based \*\*sports shop billing and inventory management system\*\* developed as a Class 12 school project.



The project contains two implementations:



\* \*\*Console Version\*\* — Command-line based billing system

\* \*\*GUI Version\*\* — Graphical application built using Tkinter



Product information is stored in a CSV file and processed using Pandas.



\---



\## About the Project



\*\*A.S Sports Shop Billing System\*\* simulates the basic operations of a sports retail store.



The system allows customers to view available products, purchase items, calculate their total bill, and provide ratings or feedback.



The project was developed to apply Python programming concepts to a practical real-world application.



\---



\## Features



\* View available sports products

\* CSV-based product inventory

\* Purchase multiple products

\* Enter product quantities

\* Calculate total purchase amount

\* Generate and display bills

\* Customer name validation

\* 10-digit phone number validation

\* Customer rating system

\* Feedback collection

\* Pandas-based data handling

\* Tkinter graphical user interface
