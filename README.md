\# A.S Sports Shop Billing System



A Python-based sports shop billing and inventory management system developed as a Class 12 school project.



The project includes both a \*\*console-based version\*\* and a \*\*Tkinter GUI version\*\*, using Pandas and CSV for product data management.



\## Features



\* View available sports products

\* Product inventory stored in CSV format

\* Purchase multiple products

\* Calculate total bill amount

\* Customer name validation

\* 10-digit phone number validation

\* Generate and display bills

\* Customer rating system

\* Feedback collection for lower ratings

\* Tkinter-based graphical interface



\## Technologies Used



\* \*\*Python\*\*

\* \*\*Pandas\*\*

\* \*\*Tkinter\*\*

\* \*\*CSV\*\*

\## Installation



\### 1. Clone the repository



```bash

git clone https://github.com/Adix10/AS-Sports-Shop-Billing-System.git

```



\### 2. Open the project folder



```bash

cd AS-Sports-Shop-Billing-System

```



\### 3. Install the required package



```bash

pip install -r requirements.txt

```



\## Running the Project



\### Console Version



From the repository root:



```bash

python sports\_shop\_billing/sports\_shop\_billing.py

```



\### Tkinter GUI Version



From the repository root:



```bash

python sports\_shop\_billing/sports\_shop\_billing\_gui.py

```
